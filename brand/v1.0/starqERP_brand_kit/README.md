# starqERP reusable brand kit

Contents:
- `logos/` — SVG masters for wordmark, house mark, logomark, lockups, and app icon
- `icons/` — reusable line icon samples and app icon PNG exports
- `tokens/` — CSS + JSON design tokens
- `templates/` — reusable HTML for invoice, landing hero, and two emails
- `docs/` — written brand and voice guidance

The SVG logo artwork is self-contained vector artwork and does not require a font file. Product typography is specified separately as Lexend / Manrope / Fira Code / Noto Sans Thaana. Font files are intentionally not included.

## Originality / collision audit
The mark was drawn from the product brief after reviewing the ERP/accounting category for common visual tropes. It intentionally avoids the dominant generic territories: cubes, hexagons, circular badges, node graphs, literal stars, swooshes, and search/document symbols. This is a design originality check, not legal trademark clearance.
