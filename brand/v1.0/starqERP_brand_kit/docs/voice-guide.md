# starqERP voice system

## Six principles
1. Say what happened, not how clever the software is.
2. Put the owner’s next action in the first sentence.
3. Use specific nouns: invoice, job, item, supplier, payment.
4. Never joke about money, debt, overdue balances, or errors.
5. Prefer short international English; avoid idiom and jargon.
6. AI is a helper in the sentence, never the headline.

## Before → after
- “Oops! Nothing here yet.” → “No customers yet. Add your first customer to create jobs and invoices.”
- “Something went wrong.” → “We couldn’t save this invoice. Your changes are still here. Try again.”
- “Success! Payment captured 🎉” → “Payment recorded. MVR 2,500 was added to this invoice.”
- “You’re all caught up!” → “No overdue work right now.”
- “This customer is naughty and overdue.” → “Payment is 12 days overdue. MVR 4,800 remains unpaid.”
- “Delete forever?” → “Delete this item? It will be removed from future transactions. Existing records stay unchanged.”
- “AI found an anomaly.” → “Stock for Paint Thinner is lower than expected. Review the last 7 days of usage.”
- “No results :(” → “No suppliers match ‘marine paint’. Check the spelling or add a supplier.”
- “Invalid amount.” → “Enter an amount greater than MVR 0.00.”
- “Sync failed.” → “Couldn’t sync 3 changes. Keep this screen open; starqERP will retry when the connection improves.”

## Words we do not use
magic, revolutionary, game-changing, effortless, seamless, delightful, naughty, oops, killer feature, AI-powered (as a lead claim), compliant, approved, certified, audited
