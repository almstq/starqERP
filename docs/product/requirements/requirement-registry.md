# StarqERP Requirement Registry

This file contains all product requirements for StarqERP, traced from competitive research, product principles, and architectural decisions. Each requirement maps to one or more tasks in `starq-erp-tasks.json`.

|----|------------|-------------|---------------------|----------------|----------------|---------------|------------|---------------|-----------------------|---------------------|--------------|---------------------------|
| Unique identifier (e.g., CORE-001) | Short name of capability | Detailed description | What competitors do/publicly document/not document/infer/unknown | Our decision (Must Have / Later / Don't Copy / Opportunity to Beat) | Must Have / Later / Don't Copy / Opportunity to Beat | Target module (e.g., Accounting, Inventory) | Upstream requirement ID(s) | Target release or stage (e.g., Stage 1, R2) | Not Started / In Progress / Done / Blocked | Testable criteria | Test ID/link | Reference to research doc, benchmark, etc. |
