## 6. Traps I hit, so you don't

1. **`PUBLIC_BUILD=1 npm run prebuild` before committing Nexus `src/data`.** A plain regenerate
   embeds Tier 1 detail and the pre-commit hook blocks it — correctly.
2. **Check the board before acting on any inbox brief, including one Elder wrote.** I dispatched
   @vscode at SERP-124, which had been done for four days. It caught the error, I did not.
3. **A literal grep for `accountCode: '____'` misses computed codes.** The worst defect found today
   was `paymentMethod === 'Cash' ? '1000' : '1010'` — posting to the root of the asset tree. Only a
   failing test found it.
4. **A green test suite is not evidence of correctness.** `payroll.test.ts` passed against the wrong
   accounts for as long as nobody checked which accounts those were.
5. **Node ESM on Windows needs `file:///D:/...`** for absolute imports; bare `D:/` fails. Backticks
   inside template literals break Room-post scripts.
