**Author**: Antigravity
**Status**: Implemented & Verified
**Target**: starqERP Core Data Engine (`web/src/domain/ingestion`, `web/src/components/ingestion`)
**Dependencies**: SERP-289 (Done)

---

## 1. Overview & Context

Small-to-medium enterprises in the Maldives migrating to starqERP frequently supply historical master data and opening balances in varied spreadsheet formats (CSV, TSV, XLSX) generated by legacy ERPs, Quickbooks, or manual Excel templates. 

Previous approaches suffered from:
1. **Third-party Bloat**: Heavy npm libraries (e.g. SheetJS/xlsx) adding hundreds of kilobytes and potential CVE vectors.
2. **Brittle Parsing**: Failure to handle UTF-8/UTF-16 BOMs, CRLF/LF line endings, dynamic delimiters (`,`, `;`, `\t`, `|`), or quoted multiline entries.
3. **Missing Maldivian Localization**: No validation for Maldivian phone numbers (`+960` prefix, `7xxxxxx`/`9xxxxxx` mobile, `3xxxxxx` landline) or MIRA Taxpayer Identification Numbers (TIN).
4. **Non-Atomic Ingestion**: Partial batch ingestion leaving inconsistent orphaned records when a row midway failed validation.

SERP-302 delivers a self-contained, zero-dependency ingestion framework with RFC-4180 compliance, native browser-stream XLSX extraction, Maldivian schema validation, duplicate key detection, double-entry balance verification, and atomic commit semantics.

## 2. Core Architecture

The architecture is partitioned into pure domain logic and interactive Material 3 UI:

```
web/src/
├── domain/ingestion/
│   ├── types.ts              # Core contracts, schemas, validation summaries
│   ├── csvParser.ts          # RFC-4180 streaming parser & auto-delimiter detector
│   ├── xlsxParser.ts         # Zero-dependency PKZip/OpenXML streaming decompressor
│   ├── schemas.ts            # Target schemas (contacts, products, opening_balances)
│   ├── validator.ts          # Row validator, duplicate finder & error CSV exporter
│   ├── batchExecutor.ts      # Atomic batch execution with all-or-nothing rollback
│   └── index.ts              # Public API module export
└── components/ingestion/
    └── DataIngestionWizard.tsx # 4-step Material 3 wizard (Upload, Map, Review, Commit)
```

## 3. Specifications & Capabilities

### 3.1 Parsers

- **Universal CSV Parser (`csvParser.ts`)**:
  - Compliant with RFC-4180.
  - Automatically detects delimiter by statistical score across candidate delimiters (`,`, `;`, `\t`, `|`).
  - Correctly handles escaped quotes (`""`), quoted newlines, and strips UTF-8 BOM (`\uFEFF`).
  - Supports streaming chunking for multi-megabyte files.

- **Zero-Dependency XLSX Parser (`xlsxParser.ts`)**:
  - Uses the standard web API `DecompressionStream('deflate-raw')` to decompress zip central directory and file streams without third-party dependencies.
  - Parses OpenXML workbook (`xl/workbook.xml`), shared strings table (`xl/sharedStrings.xml`), and first worksheet (`xl/worksheets/sheet1.xml`).
  - Accurately converts column alphanumeric references (`A1`, `BC12`) into zero-indexed grid coordinates.

### 3.2 Target Schemas & Maldivian Localization (`schemas.ts`)

1. **`contacts`**:
   - `name` (required, string)
   - `type` (required, `customer` | `supplier` | `both`)
   - `phone` (optional, validated against Maldivian telecom rules: 7 digits, starting with 3, 7, 8, or 9; accepts optional `+960` or `960`)
   - `email` (optional, email format)
   - `tin` (optional, MIRA TIN: 7 digits)
   - `credit_limit` (optional, non-negative number)

2. **`products`**:
   - `sku` (required, unique key)
   - `name` (required, string)
   - `barcode` (optional, alphanumeric barcode)
   - `cost_price` (required, non-negative decimal)
   - `selling_price` (required, non-negative decimal, must be >= cost_price)
   - `tax_rate` (optional, default 8% for Maldivian GST)
   - `stock_quantity` (optional, non-negative number)

3. **`opening_balances`**:
   - `account_code` (required, chart of accounts code)
   - `account_name` (required)
   - `debit` (required, non-negative decimal)
   - `credit` (required, non-negative decimal)
   - **Double-Entry Constraint**: Total sum of debits MUST exactly equal total sum of credits across the entire dataset.
   - **Foreign Reference Constraint**: `account_code` must exist in active Chart of Accounts (`chart_of_accounts.code`).

### 3.3 Foreign Reference Validation (SSOT AC2)

- Supports referential integrity lookups before batch commit.
- Target schema fields can declare `foreignReference: { targetTable, targetField }`.
- `IngestionValidationContext.foreignReferences` supplies in-memory Sets of valid foreign entities (e.g. `chart_of_accounts.code`, `categories.name`, `currencies.code`).
- Rows referencing non-existent foreign keys are flagged with descriptive validation errors and blocked from committing.

### 3.4 Smart Column Auto-Mapping

- Computes fuzzy confidence scores using normalized exact match, substring containment, and alias dictionary.
- Automatically pairs common legacy headers:
  - `"Telephone"`, `"Mobile"`, `"Cell"` → `phone`
  - `"Item Code"`, `"Product ID"`, `"Item#"` → `sku`
  - `"Retail Price"`, `"Rate"`, `"MVR"` → `selling_price`
  - `"Tax Identification"`, `"MIRA TIN"` → `tin`

### 3.5 Atomic Batch Execution Engine (`batchExecutor.ts`)

- **All-Or-Nothing Mode**: If any row fails validation or DB insertion, the entire transaction is rolled back. No partial corruption.
- **Skip-Invalid Mode**: Commits all valid rows within a single atomic batch and outputs an error manifest of rejected rows with precise row numbers and failure reasons.

### 3.6 Browser Safety & Ingestion Guards

- **File Size Guard**: Hard 50MB ceiling enforced on file upload before reading or decompressing into memory.
- **Row Bound & RFC-4180 Parsing**: Hard 50,000-row cap enforced (`maxRows: 50000`). Quotes mid-field in unquoted fields (e.g. `5" pipe`) treated as literal characters per RFC-4180 rather than opening quote mode.
- **Component Reachability**: `DataIngestionWizard` is a modular, self-contained component exported from `@components/ingestion/DataIngestionWizard`, designed for embedding in Settings / Bulk Data Import flows.
