# starqERP — Data Processing Agreement (DPA)

*Effective Date: 26 August 2026*

This Data Processing Agreement ("DPA") governs the processing of business and personal data by Starq Technologies ("Data Processor") on behalf of the client ("Data Controller").

## 1. Processing Scope
The Processor processes Customer Data solely to deliver the ERP, POS, and financial accounting services requested by the Controller, in strict accordance with the documented instructions of the Controller.

## 2. Confidentiality & Security Measures
1. Personnel authorized to process data are bound by strict confidentiality obligations.
2. Technical and organizational measures include TLS 1.3 encryption in transit, AES-256 encryption at rest, role-based access control, and edge-level request authorization.

## 3. Data Transfers & Sub-Processing
The Controller authorizes the Processor to engage Supabase and AWS as infrastructure sub-processors in the Singapore (Asia-Southeast) hosting region.

## 4. Exit Assistance & Data Return
Upon termination of services, the Processor shall return all Controller data in open JSON/CSV format within **14 business days** and permanently purge production copies following a 30-day grace period.

## 5. Non-GST Registration Clause (DEC-073 §10)
Starq Technologies is non-GST registered. No statutory tax calculations or withholding claims are made on Processor service charges.
